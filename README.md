# 一次一个练习，学习 Rust

你听说过 Rust，但一直没有机会尝试？\
这门课程就是为你准备的！

你将通过完成 100 个练习来学习 Rust。\
从对 Rust 一无所知到能够开始编写自己的程序，一次一个练习，循序渐进。

> [!NOTE]
> 本课程由 [Mainmatter](https://mainmatter.com/rust-consulting/) 编写。\
> 它是我们 [Rust 工作坊系列](https://mainmatter.com/services/workshops/rust/) 中的一门培训课程。\
> 如果你正在寻找 Rust 咨询或培训，请查看我们的[主页](https://mainmatter.com/rust-consulting/)！

## 开始学习

前往 [rust-exercises.com](https://rust-exercises.com)，按照那里的说明开始学习本课程。

## 系统要求

- **Rust**（按照[此处的说明](https://www.rust-lang.org/tools/install)安装）。\
  如果你的系统上已安装了 `rustup`，请运行 `rustup update`（或根据你安装 Rust 的方式选择其他合适的命令）
  以确保你运行的是最新的稳定版本。
- _（推荐但非必需）_ 一款支持 Rust 自动补全的 IDE。
  我们推荐以下之一：
  - [RustRover](https://www.jetbrains.com/rust/)；
  - [Visual Studio Code](https://code.visualstudio.com) 配合
    [`rust-analyzer`](https://marketplace.visualstudio.com/items?itemName=matklad.rust-analyzer) 扩展。

[`solutions` 分支](https://github.com/mainmatter/100-exercises-to-learn-rust/tree/solutions) 中找到练习的参考答案。
